This repository contains my solutions for Task 4 of the Data Science Internship – February 2026. The assignment focuses on Python functions, loops, conditional statements, input validation, and real-world problem-solving.

1. **Mobile Recharge Validation System** – Validates recharge amounts and plans, with retry support.
2. **Inventory Reorder Alert System** – Checks stock levels and identifies products requiring reorder.
3. **Student Result Processing System** – Calculates average marks and determines pass or fail status.

5. **Employee Attendance Eligibility Checker** – Calculates attendance percentage and determines eligibility.
6. **Password Strength Checker** – Validates password length, digits, and required special characters.
